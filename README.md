# Medical Revolution - Hospital Portal

A responsive web application designed for hospitals to help patients check available medical facilities and submit pre-admission forms online to save time upon arrival.

## Features
- **Hospital Homepage (`index.html`):** Displays facility highlights including 24/7 Emergency Care, Advanced ICU, and Diagnostics/Lab services.
- **Pre-Admission Form (`form.html`):** Allows patients to enter their personal details, age, gender, contact number, preferred department, and symptoms.

## Tech Stack
- HTML5
- CSS3
- JavaScript
